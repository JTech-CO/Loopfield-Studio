# 80개 패턴 라이브러리 검증 / 2026-10-08

[English](VALIDATION-2026-10-08.md) · **한국어** · [패턴 목록](PATTERNS-KR.md)

유한 프랙탈 곡선 5개, 2D 구성 6개, 입체 모델 5개를 추가했습니다. 총 프랙탈 23개, 기하학 모션 29개, 입체 패턴 19개, 유기적 패턴 8개, 코드 시작점 1개입니다. 기존 64개의 셰이더와 썸네일은 보존했습니다.

- Node 회귀검사 **36개 통과**: ID·이름·소스 중복, 조절값 범위, EN/KR 표시, 운영 `CNAME` 보존을 확인했습니다.
- 실제 Chromium WebGL 2 / ANGLE SwiftShader에서 **80개 모두** 컴파일·화면 표시·움직임·루프 끝점 검사를 통과했습니다. 검사 해상도는 240 × 144입니다.
- 새 16개 패턴의 개별·전체 조절값 양 끝 **138개 조합**을 검사했습니다. 모든 조절 항목이 화면을 변화시키고, 검사한 양 끝에서도 도형이 표시되며 GL 오류가 없었습니다.
- 기본값의 최대 RGB 끝점 평균 절대 차이는 약 **0.013947 / 255**, 전체 조절값 양 끝의 최대 차이는 약 **0.008189 / 255**였습니다. 기존 통과 기준은 0.5 / 255입니다. 작은 해상도의 표본 검사이며 모든 기기에서의 수학적·픽셀 단위 일치를 보장하는 결과는 아닙니다.
- 원본 HTML/CSP를 유지한 로컬 HTTP에서 80개 목록, EN·Prism Bloom 시작, 새 16개 선택·초기화, EN/KR 이름·검색, 자동 제목과 수동 제목 유지를 확인했습니다. 실행 오류와 실패한 리소스 요청은 없었습니다.
- 실제 셰이더로 320 × 180 WebP 썸네일 16개를 생성하고 구도를 확인했습니다. 흔들림과 확대 호흡 시 곡선이 가장자리에 닿지 않도록 여백을 확보했습니다.

## 실제 MP4 표본 검사

Windows Chromium의 **Intel UHD Graphics / ANGLE Direct3D 11**에서 `koch`, `five-cell` 각각 **1920 × 1080, 24 fps, 2초 H.264 MP4** 생성과 재생을 통과했습니다. 코덱은 `avc1.640028`, 인코더 선호 설정은 software입니다. 브라우저 디코딩 결과 해상도와 길이가 정확하고 재생 위치가 진행됐습니다.

앞서 SwiftShader를 강제한 영상 출력 검사는 120초의 검사 취소 제한에 걸렸습니다. 실제 GPU 렌더링에서는 같은 대표 패턴들이 통과했습니다. 소프트웨어 WebGL은 작은 해상도의 반복 가능한 그래픽 검사에 유용하지만 출력 성능을 입증하지는 않습니다. 이번 결과로 모든 패턴의 4K·장시간 출력, 모든 GPU·인코더 조합을 검증했다고 볼 수는 없습니다.
