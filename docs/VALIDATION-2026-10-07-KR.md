# 64개 패턴 라이브러리 검증 / 2026-10-07

[English](VALIDATION-2026-10-07.md) · **한국어** · [패턴 목록](PATTERNS-KR.md)

- Node 회귀검사 **35개 통과**. 64개 ID·영문명·한국어명·GLSL 소스가 서로 다르고, 모든 슬라이더 선언의 범위와 번역을 확인했습니다.
- 실제 Chromium WebGL 2에서 **64개 모두** 컴파일, 비어 있지 않은 렌더, 움직임을 확인했습니다. 재현 가능한 로컬 검사를 위해 ANGLE SwiftShader를 사용했습니다.
- 240 × 144에서 기본값의 시작·끝 경계가 **64개 모두 일치**했습니다. RGB 평균 절대 차이의 최댓값은 약 **0.000704 / 255**, 기존 통과 기준은 0.5 / 255입니다.
- 추가 패턴의 개별 슬라이더 최솟값·최댓값, 모든 슬라이더를 동시에 양 끝으로 둔 **242개 경우**를 검사했습니다. WebGL 오류가 없었고, 전체 조절값 양 끝에서도 루프 경계 샘플이 일치했습니다. 새 슬라이더는 모두 적어도 한쪽 끝에서 렌더 결과를 바꿉니다.
- 새 320 × 180 WebP 썸네일 **32개**는 실제 셰이더 프레임에서 생성했습니다. 모아 보기로 시각 검토한 뒤 곡선·곡면의 기본 크기와 팔면체 내부 공동을 조정했습니다.
- 원본 HTML/CSP를 유지한 상태에서 시작 화면, 64개 목록, 테서랙트 선택, 값 초기화, 테서랙트·만델벌브·황금각 씨앗·뫼비우스 변환 격자의 4레이어 합성을 확인했습니다. 처리되지 않은 예외와 CSP 위반이 없었습니다.
- 테서랙트 한국어·영어 이름, 검색과 조절 항목을 확인했습니다. 기존 패턴 소스와 썸네일은 보존했습니다.

그래픽 검사는 `python -X utf8 tests/qa_library.py`로 재현합니다. [개발 검사 안내](../tests/README-KR.md)를 참고하세요. 로컬 결과는 `test-artifacts/browser/library-64.json`, `library-expansion.png`, `library-shell.json`, `tesseract-studio.png`에 저장됩니다.

루프 검사는 샘플 비교이며 모든 출력 해상도에서의 수학적 증명은 아닙니다. 새 네이티브 MP4·4K 인코더 인증이나 GitHub Pages 배포 검사를 의미하지 않습니다. 이번 확장은 외부 텍스처·서비스·프로젝트 업로드 없이 반복 횟수를 제한한 로컬 절차적 셰이더를 추가합니다.
