# 패턴 라이브러리 / 80개

[English](PATTERNS.md) · **한국어** · [README](../README-KR.md)

각 패턴은 독립적인 생성 원리와 GLSL 소스를 갖습니다. 표에는 패턴별 형태 조절 항목을 적었습니다. 공통 확대·회전·시작 위상·시드, 팔레트, 레이어 합성과 마무리 효과도 함께 사용할 수 있습니다.

테서랙트, 16셀, 24셀은 실제 4차원 꼭짓점과 모서리를 회전시켜 3차원으로 투영한 뒤 화면에 그립니다. 곡면 메시와 매듭은 절차적으로 계산한 3D 선 구조이며, 멩거 스펀지·만델벌브·팔면체·구면 껍질은 레이마칭으로 렌더링합니다.

5셀은 서로 같은 거리에 있는 꼭짓점 5개와 모서리 10개를 가진 4차원 정단체입니다. 호프 섬유는 3차원 구면을 입체 투영한 실제 연결 원입니다. 클라인 병은 자기 교차가 있는 3D 표현이며, 카테노이드·헬리코이드는 연속 극소곡면 식으로 변형하고 뒤팽 사이클라이드는 토러스를 구에 반전해 만듭니다. 이 모델들은 불투명한 삼각형 메시 대신 표본을 연결한 선 메시로 표현합니다.

코흐·드래곤·힐베르트·고스퍼는 서로 다른 유한 L-system 규칙을 사용하며, 좌표를 편집 가능한 셰이더 안에 포함합니다. 피타고라스 나무는 직각삼각형의 두 변 위에 정사각형을 세우는 구성을 따릅니다. 재귀 깊이가 높을수록 GPU 계산량이 늘어납니다. 펜로즈는 로빈슨 분할로 만든 유한 P3 마름모 영역이며, 쌍곡 타일링은 유효한 `{p,3}` 조합 중 `p = 7~10`을 지원합니다. 행킨 별은 4.8.8 팔각형·정사각형 타일링을 사용합니다. 푸리에 경로는 정수 고조파로 닫힙니다. 진자 파동은 비선형 물리 시뮬레이션이 아닌 조화운동이며, 짧은 영상에서는 정수 주파수를 제한해 일부 진자가 같은 주파수를 가질 수 있습니다. 뢸로 회전자는 일정한 폭의 경계 상자를 유지합니다.

기본 애니메이션은 주기적인 각도와 순환 좌표로 구성합니다. 루프 검사는 작은 해상도의 샘플 비교이며, 깊은 프랙탈이나 미세한 선에는 부동소수점·샘플링 오차가 생길 수 있습니다.
