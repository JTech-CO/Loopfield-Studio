# 패턴 라이브러리 / 64개

[English](PATTERNS.md) · **한국어** · [README](../README-KR.md)

각 패턴은 독립적인 생성 원리와 GLSL 소스를 갖습니다. 표에는 패턴별 형태 조절 항목을 적었습니다. 공통 확대·회전·시작 위상·시드, 팔레트, 레이어 합성과 마무리 효과도 함께 사용할 수 있습니다.

테서랙트, 16셀, 24셀은 실제 4차원 꼭짓점과 모서리를 회전시켜 3차원으로 투영한 뒤 화면에 그립니다. 곡면 메시와 매듭은 절차적으로 계산한 3D 선 구조이며, 멩거 스펀지·만델벌브·팔면체·구면 껍질은 레이마칭으로 렌더링합니다.

기본 애니메이션은 주기적인 각도와 순환 좌표로 구성합니다. 루프 검사는 작은 해상도의 샘플 비교이며, 깊은 프랙탈이나 미세한 선에는 부동소수점·샘플링 오차가 생길 수 있습니다.
