이 기기에서 직접 검증

정적 파일만으로 실행하는 테스트이다. 네이티브 MP4 테스트는 실제 WebGL 프레임을 실제 브라우저 H.264 인코더로 인코딩한다. 자동 실행하지 않으며 서버로 데이터를 보내지 않는다.

1. 셰이더 · 루프

80개 프리셋의 GLSL 컴파일, 비어 있지 않은 렌더링, 시작/끝 샘플 비교, 4레이어 합성, 컴파일 실패 시 복구, discard의 이전 프레임 잔상 방지를 검사한다.

2. 실제 네이티브 MP4

선택한 해상도로 2초 · 선택 FPS (24/30/60)을 생성한다. HTTPS 또는 localhost와 해당 크기의 H.264 인코더가 필요하다. 낮은 사양에서는 오래 걸릴 수 있다.

검사 결과

아직 실행하지 않았다.

이 페이지의 통과 결과는 테스트한 브라우저·기기·설정에만 해당한다. 네이티브 파일 선택기의 권한, 실제 디스크 직접 저장, 60초 장시간 출력은 Studio에서 따로 확인한다.
